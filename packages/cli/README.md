# fullfiller-cli

## Run on dev environment

- `npm run build && node dist/bundle.js 'harry potter'`

## Install

- `npm i -g fullfiller-cli`

## Usage

- `fullfiller-cli 'harry potter' -l es -u words -q 250 -f html`
- `fullfiller-cli -h` = list all available options
